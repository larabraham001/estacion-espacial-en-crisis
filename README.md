### Requisitos
- CMake 3.16 o superior
- Compilador C++17 (Clang o GCC)
- Git (SFML se descarga automáticamente al configurar)

### Compilar y ejecutar
    cmake -S . -B build
    cmake --build build
    ./build/EstacionEnCrisis

La primera compilación tarda varios minutos porque descarga y compila SFML.
